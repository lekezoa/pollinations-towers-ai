# Towers AI 🏢

[![Made with pollinations.ai](https://raw.githubusercontent.com/pollinations/pollinations/main/packages/ui/src/brand/badge-made-with.svg)](https://pollinations.ai/?ref=badge)

**Towers AI** is an interactive multi-agent company simulation built on **Pollinations AI**, created for **POLLEN-QUEST #17999**.

## 🏙️ Concept
Inspired by [The Towers](https://thetowers.ai/), every floor represents an autonomous enterprise managed by specialized AI agent personas (Design, Analytics, Legal) powered by Pollinations text and image models. Users ride the elevator, interact with corporate lead agents, and dispatch real workflows using their Pollen tokens.

## 🚀 Features
- **Interactive Elevator Navigation:** Switch between specialized business floors in real time.
- **Autonomous Multi-Agent Personas:** Dynamic prompts backed by Pollinations LLMs.
- **BYOP Integration:** Prepared for Bring Your Own Pollen user authorization.
